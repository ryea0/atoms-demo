# PRD：轻量待办事项应用（Todo）

> 版本 v1（mock 样例）　作者：PM　状态：已评审
> 一句话需求：做一个能记录、勾选、删除待办的简洁应用。

## 1. 背景与目标

用户需要一个零门槛的待办清单：打开即用、无需登录、数据直观可见。
本期目标是跑通「新增 → 勾选完成 → 删除」的主闭环，界面清爽、加载快。

## 2. 功能清单

| 编号 | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| F1 | 新增待办 | P0 | 输入标题回车或点「添加」即创建，标题非空校验 |
| F2 | 待办列表 | P0 | 倒序展示；空列表显示引导文案 |
| F3 | 勾选完成 | P0 | 点击复选框切换完成态，完成项划线置灰 |
| F4 | 删除待办 | P1 | 每项提供删除按钮，删除即时生效 |
| F5 | 进度统计 | P2 | 顶部显示「已完成 x / 共 y」 |

非功能：首屏 < 1s；移动端可操作（触控目标 ≥ 44px）；无第三方依赖安装。

## 3. 用户故事

- US1：作为用户，我想快速记下一件事，以免忘记。
- US2：作为用户，我想勾掉已完成的事，获得完成感。
- US3：作为用户，我想删除不再需要的条目，保持清单干净。
- US4：作为移动端用户，我想在手机上单手完成以上操作。

## 4. 验收标准

- AC1：空标题提交时不创建条目并给出提示。
- AC2：新增后列表立即出现新条目，输入框清空。
- AC3：勾选后条目划线置灰，计数同步更新；取消勾选可恢复。
- AC4：删除后条目从列表消失，计数同步更新。
- AC5：刷新页面回到初始内存态数据（本期不做持久化，见 §5 边界）。

## 5. 边界与不做

- 本期不做多端同步、账号体系、截止日期与提醒。
- 数据为内存态：刷新重置（生成应用运行在浏览器沙箱，禁用 localStorage）。
